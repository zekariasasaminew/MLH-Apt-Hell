# Hellow

A Zillow parody for MLH: a rental site that looks polished on the first visit and gets more frustrating the more
you use it.

```bash
npm install
npm run dev
```

Open http://localhost:3000. The pain meter in the bottom-left corner shows how annoyed the site thinks you are
(Ctrl+Shift+P toggles it on deployed builds).

**Contributing:** read [AGENTS.md](AGENTS.md) first. It is the source of truth for how the pain system works, how to
add an annoyance, who owns what, and the rules for working in parallel. Point your coding agent at it too.

Hellow is a parody built for a hackathon and is not affiliated with Zillow Group, Inc.
